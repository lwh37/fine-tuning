# Public release manifest

## Included

- Project README and dataset card.
- Synthetic TSV/JSONL examples.
- Sanitization, split and cascade evaluation scripts.
- Example cascade configuration and tests.

## Excluded

- Original XLSX, CSV, TXT and model-training JSON files.
- User-authored text, contact details and session identifiers.
- Internal service names, URLs, task IDs and taxonomy IDs.
- Model checkpoints, caches and generated Bad Case files.

The release is intentionally a reproducible method package rather than a copy of the private corpus.
